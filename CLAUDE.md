# personal-website

React 19 + Vite 8 + TanStack Router, prerendered to static HTML. A home page, plus a
print-exact CV route that also emits committed PDFs. pnpm.

## Working agreement

- Terse — in responses, and especially in code comments. Comment the WHY, never the WHAT.
- Don't assume. Don't hide confusion. Surface tradeoffs.
- Define success criteria before starting, then loop until verified.
- Check for an existing pattern or helper before writing a new one.
- Types > tests > manual checks. Encode the invariant in the type system where you can;
  write a test where you can't.
- Ask before adding a dependency. Bundle budgets are hard gates — check `pnpm size`.
- Build tooling for yourself; if it's generally useful, commit it under `scripts/` or make it a test.
- Multi-step work: adversarial self-review at each step. Once execution is underway you
  may commit as you go — but never the first change of a session, and stage files by
  name, never `git add -A`.

## Commands

    pnpm dev          vite dev server
    pnpm build        tsc -b → client build → SSR build → prerender.js → headers.js
    pnpm test         vitest run
    pnpm typecheck    tsc -b --noEmit
    pnpm lint         biome check .   (formats AND lints)
    pnpm size         size-limit budgets
    pnpm knip         dead code / unused deps
    pnpm prepress     build + regenerate CV pagination and PDFs
    pnpm hooks        install the pre-push hook (once per clone)

`knip` and `size` are manual — not wired into the build or any hook. Run them after
touching dependencies or CSS.

## Architecture

- `src/routes/` — file-based (`__root`, `index`, `cv`, `cv.lazy`); tree generated into
  `routeTree.gen.ts`. The CV component lives in `cv.lazy.tsx` to keep the paginator out
  of the home bundle. `?lang=de|pt` is validated in `__root`; English omits the param.
- `src/content/<locale>/*.md` — markdown with comark directives (`::project`, `::topic`,
  `::person`). `vite/comark.ts` parses and zod-validates at build time and emits JSON, so
  no parser ships. Fields marked `invariant` in `src/content/schema.ts` must be
  byte-identical across locales or the build fails. Site: en/de/pt. CV: en/de.
- `src/components/` chrome · `sections/` home page · `cv/` the CV document.
- `src/index.css` is the entire Tailwind v4 config — tokens, `@theme`, `@utility`.
- `src/build/` — SSR-only emitters (JSON-LD, llms.txt, sitemap).

## Conventions

- Tabs, width 2, LF, double quotes. `.editorconfig` is authoritative; Biome honours it.
- Biome sorts Tailwind classes, including inside `clsx()`. Static-only `className`s stay
  plain strings; use `clsx` only when a class is conditional.
- No path aliases — imports are relative.
- Tests are colocated `*.test.ts`, environment `node`, pure functions and real content
  fixtures. Nothing renders React. Never put a test under `src/routes/` — the router
  plugin scans it as a route.
- Colors come from semantic tokens (`text-ink-2`, `text-mut`, `text-faint`, `bg-band`,
  `border-rule`), which re-point under `[data-theme]`. Never use a `dark:` variant for
  color — it is reserved for the few places geometry differs between themes.
- Running prose uses `prose-body`. To resize it set `[--prose-size:…]` — never pair a
  `text-*` utility with it; equal specificity clobbers the mono leading.

## Sharp edges

- **CV artifacts are committed.** `pagination.generated.ts` and `public/cv.*.pdf` are
  regenerated by `pnpm prepress`, and the pre-push hook rejects the push if they drift.
  Touching CV markup or print CSS means re-running prepress and committing the result.
- **`src/components/cv/fit.ts` is duplicated** as `FIT_SCRIPT` in `scripts/prerender.js`.
  Change both or `/cv` breaks. It measures `window.screen`, not the viewport — deliberate,
  the viewport causes an iOS feedback loop.
- **`scripts/headers.js` asserts inline `<script>` counts** (2 on `/`, 3 on `/cv`) to
  compute CSP hashes. A new inline script fails the build there.
- **The CV scripts read the DOM by selector contract**: sheets `[class*="21cm"]`, the
  offscreen measuring rig `[class*="200vw"]`, blocks `.break-inside-avoid`, language on
  `main[lang]`. Renaming those classes breaks pagination and PDF output silently.
- `@page { size: A4 }` must stay in step with `w-[21cm] h-[29.7cm]` in `cv/Sheet.tsx`.
- `scripts/browser.js` needs a local Chrome (set `CHROME_PATH` if it is not in the usual
  places). Run CV scripts from the repo root — locale discovery uses a relative path.
- PDFs are byte-normalised (fixed `/CreationDate`, `/ID`) so the hook's diff check works.
